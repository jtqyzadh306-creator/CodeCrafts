جلسه ۱ — پایتون چیست؟

پایتون یکی از محبوب‌ترین و پرکاربردترین زبان‌های برنامه‌نویسی دنیاست.
این زبان در سال ۱۹۹۱ توسط Guido van Rossum طراحی شد و امروز در صدها هزار پروژه واقعی استفاده میشه.
نام پایتون از یه برنامه کمدی بریتانیایی به اسم Monty Python گرفته شده — نه از مار پایتون!

🐍 چرا پایتون؟

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

۱. 📖 سادگی و خوانایی

پایتون شبیه‌ترین زبان برنامه‌نویسی به زبان انسانه.
کدهاش کوتاه، تمیز و قابل فهمه — حتی برای کسی که تازه شروع کرده.
فلسفه پایتون اینه که کد باید خوانا باشه — نه پیچیده.

مثال — چاپ یه متن:
 
print("Hello World")  #خروجی : Hello World

همین یه خط کافیه.
در زبان‌هایی مثل Java همین کار ۵ خط کد نیاز داره.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

۲. 🌍 همه‌جا کاربرد داره

پایتون تنها زبانیه که تقریباً در همه حوزه‌های برنامه‌نویسی استفاده میشه:

🤖 هوش مصنوعی و یادگیری ماشین
   → TensorFlow, PyTorch, Scikit-learn

📊 علم داده و تحلیل داده
   → Pandas, NumPy, Matplotlib

🌐 توسعه وب
   → Django, Flask, FastAPI

⚙️ اتوماسیون و اسکریپت‌نویسی
   → زمان‌بندی کارها، پردازش فایل، بات‌سازی

🔐 امنیت سایبری
   → تست نفوذ، آنالیز بدافزار

🎮 بازی‌سازی
   → Pygame

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

۳. 👥 جامعه بزرگ

پایتون یکی از بزرگ‌ترین جوامع برنامه‌نویسی دنیا رو داره.
یعنی هر سوالی داشتی، هزاران نفر قبلاً جوابش رو دادن.
سایت‌هایی مثل Stack Overflow پر از سوال و جواب پایتونه.
منابع آموزشی فارسی و انگلیسی زیادی هم داره.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

۴. 💰 بازار کار عالی

برنامه‌نویس پایتون یکی از پردرآمدترین مشاغل فناوری اطلاعاته.
میانگین حقوق پایتون‌کار در دنیا بالای ۱۰۰ هزار دلار در ساله.
از استارتاپ‌های کوچیک تا غول‌های فناوری از پایتون استفاده میکنن.
