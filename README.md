💻 CodeCraft

A modern programming education website designed to make learning programming more accessible and enjoyable.

🌐 About the Project

CodeCraft is a web project focused on programming education and learning resources. It provides a website interface for exploring educational content and programming-related topics.

 ✨ Features

* 📚 Programming learning pages and educational content
* 🎨 Custom user interface with a dark theme
* 📱 Responsive website design
* 🔐 Login and registration pages
* 🧩 Multiple pages organized into a single website

🛠️ Built With

* HTML5
* CSS3
* JavaScript

🚀 Getting Started

To run the project locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/jtqyzadh306-creator/CodeCrafts.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
